# Oura Research Adherence Monitor

**An open-source research informatics prototype for monitoring wearable data availability and adherence using the Oura API.**

## Overview

The Oura Research Adherence Monitor is a Python-based software project under development to support monitoring of wearable data availability in longitudinal clinical research.

The project aims to retrieve authorized Oura Ring data, evaluate the availability of recent sleep records, and identify gaps in data collection that may require follow-up by research personnel.

## Research Motivation

Continuous wearable monitoring can provide valuable insights into sleep and physiological recovery following concussion. However, missing data and inconsistent device synchronization can compromise longitudinal research.

This project explores an automated approach to identifying data collection gaps and supporting timely research staff intervention.

## Planned Features

- Secure authorization through the Oura API
- Automated retrieval of recent sleep records
- Assessment of nightly data availability and adherence
- Identification of missing records requiring follow-up
- Interactive dashboard for research personnel
- Reproducible Python code and automated testing

## Development Status

**Proof of concept — under development.**

Initial testing is limited to the developer's own Oura account. The application is not currently deployed for research participant monitoring.

## Data Privacy

The public repository contains project documentation and software development materials. It will not contain participant data, personal access tokens, or confidential research information.

Future use with research participants will require appropriate institutional authorization, privacy and security review, and applicable research ethics approval.

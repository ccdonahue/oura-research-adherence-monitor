# Terms of Service

**Oura Research Adherence Monitor**

**Last updated: October 15, 2026**

## 1. Purpose

Oura Research Adherence Monitor is an experimental software application designed to evaluate the feasibility of retrieving wearable data through the Oura API and monitoring data availability and adherence.

The application is currently under development and is intended exclusively for personal testing by its developer.

## 2. Authorized Use

During the initial development phase, the application may only be connected to Oura accounts owned by or explicitly authorized for testing by the developer.

The application is not currently available for public use or research participant monitoring.

## 3. Application Functionality

The application is being developed to support the following functions:

- Secure access to authorized Oura data through the Oura API
- Retrieval of recent sleep records
- Assessment of data availability and missing records
- Development and evaluation of an adherence-monitoring dashboard

These functions are under development and are not guaranteed to be available or operational.

## 4. Research and Clinical Limitations

The application is intended as a research informatics development tool.

It is not a medical device, does not provide medical diagnoses or treatment recommendations, and should not be used to make clinical decisions.

Any future use involving research participants will require appropriate institutional authorization, applicable research ethics approval, and additional data security review.

## 5. Data Privacy

Information accessed through the Oura API will be handled in accordance with the application's [Privacy Policy](privacy.md).

Authentication credentials and personal Oura data will not be intentionally published in the public GitHub repository.

## 6. Third-Party Services

The application uses the Oura API, which is operated by Oura Health. Access to Oura data remains subject to applicable Oura agreements, permissions, and service availability.

This project is independently developed and is not affiliated with, sponsored by, or endorsed by Oura Health.

## 7. Changes and Availability

The application is provided as an experimental prototype and may be modified, suspended, or discontinued during development.

These terms may be updated as the application evolves. The revision date will be updated when changes are made.
